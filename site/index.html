01What this is

Test an AI agent on made-up customers before it meets a real one.

Each square is one made-up customer from a recorded run. The page replays each conversation at its recorded speed. An old and a new version of the agent serve the same customers side by side. At the end the page says whether the new version is ready to release (ship) or should wait (hold).
